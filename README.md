# NetSpeed Monitor

Программа для Windows 11: показывает скорость интернета (загрузка ↓ и отдача ↑)
в реальном времени.

Три способа отображения, работают одновременно:
- **значок в области уведомлений** (трей, нижняя панель) — две строки цифр:
  сверху загрузка (зелёным), снизу отдача (оранжевым); единицы — во всплывающей подсказке;
- **компактный индикатор** — маленькое окошко поверх всех окон
  `↓ 816.39  ↑ 12.50 Мбит/с`, можно перетаскивать мышью;
- **главное окно 640×480** — большие цифры, шкала загрузки канала провайдера,
  график за последние 120 секунд, суммарный трафик за сессию, настройки
  (интерфейс и единицы; интервал и тариф; флажки «Компактный индикатор»
  и «Автозапуск» — три строки, чтобы всё помещалось и при минимальном окне 480×360).

Плюс **кнопка «⚡ Тест скорости»** — замер под полной нагрузкой в несколько
потоков, как в Интернетометре Яндекса.

Постоянный мониторинг идёт локально через счётчики сетевых адаптеров
(`psutil`): ничего никуда не отправляется и трафик не расходуется. Трафик
расходует только тест скорости, и лишь когда вы сами его запустите.

## Установка

1. Нужен **Python 3.10+** (проверено на 3.14) с `tkinter` (входит в стандартный
   установщик с python.org).
2. Запустите **`install.bat`** — он поставит зависимости (`psutil`, `pystray`, `pillow`).

## Запуск

- Двойной клик по **`run.bat`** — запуск без консоли, с главным окном.
- `python netspeed.py --tray` — запуск скрытым: только значок в трее
  (и компактный индикатор, если он был включён).
- Закрытие главного окна крестиком **не завершает** программу, а сворачивает её
  в трей. Выход — `Ctrl+Q` в окне или пункт **«Выход»** в меню значка.

### Значок в трее на Windows 11

Windows 11 прячет новые значки в область переполнения — нажмите стрелку **`^`**
слева от часов. Чтобы значок был виден всегда, **перетащите** его мышью из этой
области на панель задач (или: Параметры → Персонализация → Панель задач →
Другие значки в области уведомлений → включите NetSpeed Monitor).

Меню значка (правая кнопка): «Открыть окно», «Компактный индикатор»,
«Интерфейс ▸», «Единицы ▸» (Кбит/с, Мбит/с, КБ/с, МБ/с), «Автозапуск», «Выход».
Левый клик — открыть окно.

## Автозапуск при входе в Windows

- **`add_to_startup.bat`** — добавляет запись в реестр
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\NetSpeedMonitor`
  (`pythonw netspeed.py --tray` — скрытый запуск).
- **`remove_from_startup.bat`** — удаляет её.
- То же самое делает галочка **«Автозапуск»** в окне или в меню значка.

## Выбор интерфейса

- **Авто** (по умолчанию) — адаптер, через который идёт маршрут по умолчанию
  (Wi-Fi / Ethernet / VPN). Пересматривается каждые ~10 секунд, так что переключение
  сети отслеживается само.
- **Все** — сумма по всем адаптерам (кроме loopback). **Внимание:** при включённом
  VPN/TUN-адаптере трафик проходит и через виртуальный адаптер, и через физический,
  поэтому в режиме «Все» он учитывается **дважды**.
- **Конкретный адаптер** — из списка. Если адаптер пропадает (отключили кабель,
  VPN), программа временно переходит на «Авто».

## Единицы

- По умолчанию скорость показывается в **Мбит/с с двумя знаками после запятой**
  (`816.39 Мбит/с`, `0.00 Мбит/с`) — как в Интернетометре Яндекса
  (yandex.ru/internet). Единица фиксированная, автоматического перехода
  в Кбит/с или Гбит/с нет.
- **Переключатель Кбит/с ↔ Мбит/с** — кнопка «Единицы» в главном окне
  (на ней написана текущая единица) или клавиша **`U`** в окне.
- **КБ/с и МБ/с** (байты, шаг ×1024, как в браузерах и торрентах) — через меню
  значка в трее или правую кнопку на компактном индикаторе: «Единицы ▸»
  (Кбит/с, Мбит/с, КБ/с, МБ/с). Из байтового режима кнопка возвращает в Мбит/с.
- Пересчёт: Кбит/с = байт/с × 8 / 1000; Мбит/с = байт/с × 8 / 1 000 000;
  КБ/с = байт/с / 1024; МБ/с = байт/с / 1 048 576. 1 МБ/с ≈ 8,39 Мбит/с.
- Везде (большие цифры, «макс/средн», компактный индикатор, подсказка значка) —
  ровно два знака после запятой; на самом значке в трее места мало, поэтому там
  один знак при значениях меньше 100 и целое число при больших. Подписи сетки
  на оси графика пишутся без хвостовых нулей (`0.5`, `2`, `100`), единица
  подписана один раз — в легенде.
- Суммарный трафик за сессию всегда показывается в байтах (КБ/МБ/ГБ).

## Шкала пропускной способности

Под большими цифрами в главном окне — шкала **«Канал провайдера: 1000 Мбит/с»**.
Она показывает, какую долю тарифа провайдера занимает текущий трафик:

- **зелёная полоса** — загрузка, **оранжевая тонкая полоса** снизу — отдача;
  справа в заголовке те же значения в процентах (`↓ 12.5 %   ↑ 0.4 %`);
- **светло-зелёная вертикальная чёрточка** — пик загрузки за последние 120 секунд
  (видимое окно графика), чтобы было видно недавний максимум;
- деления под шкалой — 0 / 25 / 50 / 75 / 100 % тарифа в Мбит/с
  (`0 · 250 · 500 · 750 · 1000`); на узком окне подписи 25 % и 75 % скрываются.

Проценты всегда считаются в **Мбит/с** (байт/с × 8 / 1 000 000), независимо от
выбранной единицы отображения (Кбит/с, КБ/с и т. п.).

**Как задать тариф:** поле **«Тариф, Мбит/с»** в строке настроек рядом
с интервалом — введите число (0 < тариф ≤ 100000) и нажмите Enter или просто
перейдите в другое поле; стрелки меняют значение с шагом 50. Нечисловой ввод
или число вне диапазона отбрасывается, возвращается прежнее значение. Значение сохраняется
в `config.json` (ключ `tariff_mbit`, по умолчанию 1000). Доля тарифа также
показывается во всплывающей подсказке значка в трее
(`↓ 125.00 Мбит/с (12.5 % от 1000 Мбит/с)`), если помещается.

**Если показывает больше 100 %** (число становится красным, полоса упирается
в край): либо в настройках занижен тариф — реальный канал шире, либо выбран
режим интерфейса **«Все»** при включённом VPN/TUN-адаптере, и трафик
суммируется дважды (через виртуальный и физический адаптер). Поставьте «Авто»
или конкретный физический адаптер, либо исправьте тариф.

## Тест скорости под полной нагрузкой

Кнопка **⚡ Тест скорости** в правом нижнем углу окна (а также `Ctrl+T`, пункт
«Тест скорости…» в меню значка и в меню компактного индикатора) открывает окно
замера. Тест специально загружает канал полностью, как Интернетометр Яндекса
или Speedtest:

- **8 параллельных HTTPS-соединений на загрузку** в течение 10 секунд, затем
  **6 соединений на отдачу** в течение 8 секунд. Одно соединение гигабитный
  канал не заполняет, поэтому потоков несколько;
- первые 1,5 секунды каждой фазы не учитываются — это разгон TCP;
- показываются среднее за измерительный участок и **пик** (лучшая секунда),
  а также доля пика от вашего тарифа;
- идёт живая индикация скорости и счётчик переданного трафика, тест можно
  прервать кнопкой «Отмена».

Серверы перебираются по очереди, берётся первый ответивший: Cloudflare
(`speed.cloudflare.com`), OVH (`proof.ovh.net`), зеркало Яндекса
(`mirror.yandex.ru`). Отдача измеряется только через Cloudflare; если он
недоступен, в строке отдачи будет прочерк.

**Тест расходует трафик** — около 0,5–1,5 ГБ за прогон на гигабитном канале.
На тарифах с лимитом запускайте его осознанно.

Во время теста основной график и шкала канала показывают ту же нагрузку, так
что видно, насколько замер совпадает с показаниями адаптера.

Без окна, одной строкой JSON:

```
python netspeed.py --speedtest 10
```

## Горячие клавиши (в главном окне)

| Клавиши | Действие |
|---|---|
| `Ctrl+Q` | выход из программы |
| `Esc` | свернуть окно в трей (если трея нет и компактный индикатор выключен — завершает программу, чтобы она не осталась невидимой) |
| `Ctrl+K` | показать/скрыть компактный индикатор |
| `U` (или `Ctrl+U`) | переключить единицы Кбит/с ↔ Мбит/с |
| `Ctrl+T` | тест скорости под полной нагрузкой |

Компактный индикатор: левая кнопка — перетащить, двойной клик — открыть окно,
правая кнопка — меню.

## Файл настроек (config.json)

Создаётся рядом с `netspeed.py` (или рядом с exe) и обновляется при каждом изменении.

| Ключ | Значение |
|---|---|
| `interface` | `"auto"`, `"all"` или имя адаптера, например `"Ethernet"` |
| `units` | `"mbit"` (Мбит/с, по умолчанию), `"kbit"` (Кбит/с), `"kbyte"` (КБ/с), `"mbyte"` (МБ/с); старые `"bits"`/`"bytes"` переводятся в `"mbit"`/`"mbyte"` |
| `interval` | период замера в секундах, 0.25–5 (по умолчанию 0.5) |
| `compact_visible` | показывать ли компактный индикатор |
| `compact_pos` | положение индикатора `[x, y]` или `null` (правый нижний угол); может быть на любом мониторе, в том числе с отрицательными координатами |
| `window_geometry` | размер и положение главного окна, например `"640x480+100+100"` (`"640x480+-500+100"` — монитор слева от основного) |
| `history_seconds` | глубина графика в секундах (по умолчанию 120) |
| `tariff_mbit` | тариф провайдера в Мбит/с для шкалы канала, 0 < x ≤ 100000 (по умолчанию 1000) |

Ошибки (в том числе из обработчиков событий окна) пишутся в `netspeed.log`
рядом с программой; файл ограничен 1 МБ, предыдущая копия — `netspeed.log.1`.
Повторяющаяся ошибка отрисовки записывается не чаще раза в минуту со счётчиком
пропущенных повторов.

## Параметры командной строки

```
python netspeed.py --tray              скрытый запуск (только трей)
python netspeed.py --interface Wi-Fi   выбрать адаптер
python netspeed.py --version           версия
python netspeed.py --speedtest 10      тест скорости без окна, результат одной строкой JSON
python netspeed.py --selftest 5 --screenshot out.png
                                       самопроверка: 5 секунд работы, скриншоты, JSON-отчёт
python netspeed.py --selftest 36 --open-speedtest --screenshot out.png
                                       то же, но с открытым окном теста скорости
```

Самопроверка не пишет `config.json` и использует отдельный мьютекс, поэтому её
можно запускать параллельно с работающей программой.

## Сборка exe (необязательно)

**`build_exe.bat`** ставит PyInstaller и собирает `dist\NetSpeedMonitor.exe` —
один файл без консоли, Python на целевом компьютере не нужен. `config.json`
и `netspeed.log` в этом случае создаются рядом с exe; автозапуск из меню
программы подставляет путь к exe автоматически.

## Если что-то не так

- **«Не установлены зависимости»** — запустите `install.bat`.
- **«Программа уже запущена»** — она работает, ищите значок в трее (в области `^`).
  Экземпляр, запущенный от имени администратора, тоже считается запущенным.
- `run.bat` / `add_to_startup.bat` берут `pythonw.exe` из того же Python, что
  команда `python` (в который `install.bat` ставил зависимости); если `python`
  не на PATH — ищут `pythonw` на PATH, затем `C:\Python314\pythonw.exe`.
- Значка нет, а окно закрывается крестиком и программа завершается — значит,
  трей недоступен (так и задумано, чтобы программа не «зависала» невидимкой).
- Скорость 0 при работающем интернете — проверьте выбранный интерфейс
  (поставьте «Авто» или «Все»).
